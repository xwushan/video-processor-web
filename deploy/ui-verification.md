# 1.3.2 界面验证

处理参数的说明移到对应标题旁的问号按钮，鼠标进入显示、移开隐藏；键盘焦点可读取说明，Escape 关闭。手机点击可查看，提示位置限制在可视区域内。CPU 与 GPU 的质量、策略说明分别显示，自动模式中的 CPU 回退参数保留。

制作期间显示独立任务面板：总体进度、视频数量、并发、资源用量和逐视频进度分别展示。单行文件不再被固定最小高度拉伸；文件名、编码器、速度、状态及进度条各有位置。运行时显示暂停，暂停后显示继续制作，并保留键盘操作焦点。处理记录增加状态标签，调整日期筛选、窄屏按钮和文件信息排列。

清空视频或制作完成后会移除上一批预估表格，避免新一批视频误用旧结果；当前参数未预估成功时仍不能开始制作。

## 本地验证

- 46 项回归测试通过，JavaScript 语法、Git 空白检查与生产 Compose 配置检查通过。
- 在独立 Docker 容器和独立数据卷中，使用自生成的 90 秒、1280×720 视频完成 CPU 预估与制作。验证单视频、两视频、两层目录和超长中文文件名；两批任务都成功完成。
- 实际操作暂停、继续和从记录恢复；键盘操作后焦点落在下一步按钮，处理中的参数区保持隐藏和锁定。
- 验证鼠标离开与 Escape 关闭提示，自动模式的 CPU 策略提示与 GPU 高质量策略提示分别更新。
- 1440×900 / 1280×720 检查任务面板；1024×768 检查视频表格及记录筛选；390×844 / 320×740 检查进度、记录和参数提示。窄屏无页面横向溢出，1024 像素宽度下删除按钮未被表格截掉，320 像素宽度下提示框保持在可视区域内。
- 浏览器控制台无错误。截图保存于本地 `deploy/ui-progress-desktop.jpg` 与 `deploy/ui-parameter-help.jpg`，不纳入源码。

这些验证覆盖本地浏览器和当前容器环境；Ubuntu RTX 3090 服务器的实际部署仍按生产发布文档执行。
