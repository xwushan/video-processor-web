# 界面验证

## 1.3.3 模块对齐与编码设备提示

桌面双列布局中，视频文件与水印基础参数、水印预览与处理参数的外框分别保持同高。视频列表按内容排列，行高保持紧凑；处理参数的“预估成品”按钮位于卡片底部。平板和手机采用单列布局，各模块保持自然高度。

编码设备提示去掉显卡型号，使用通用 NVIDIA GPU 编码说明，继续按服务器配置显示自动并发目标。原型号来自运行服务的硬件检测，并非固定值；实际硬件检测和任务资源展示保留。

- 使用用户提供的 5 个视频验证待上传列表及水印预览，未修改源视频。
- 在 1728×1080 和 1440×900 下检查 CPU、GPU 和自动模式：两组卡片上下边缘一致，自动模式的 6 项参数正常排列，列表行高为 53 像素。
- 在 1024×768、390×844、320×740 下验证单列布局，页面无横向溢出；320 像素宽度下设备说明保持在可视区域内，提示不含本机显卡型号。
- 浏览器控制台无错误，JavaScript 语法和 Git 空白检查通过。桌面截图保存于本地 `deploy/ui-aligned-panels.jpg`，不纳入源码。

## 1.3.2 参数说明与处理进度

处理参数的说明移到对应标题旁的问号按钮，鼠标进入显示、移开隐藏；键盘焦点可读取说明，Escape 关闭。手机点击可查看，提示位置限制在可视区域内。CPU 与 GPU 的质量、策略说明分别显示，自动模式中的 CPU 回退参数保留。

制作期间显示独立任务面板：总体进度、视频数量、并发、资源用量和逐视频进度分别展示。单行文件不再被固定最小高度拉伸；文件名、编码器、速度、状态及进度条各有位置。运行时显示暂停，暂停后显示继续制作，并保留键盘操作焦点。处理记录增加状态标签，调整日期筛选、窄屏按钮和文件信息排列。

清空视频或制作完成后会移除上一批预估表格，避免新一批视频误用旧结果；当前参数未预估成功时仍不能开始制作。
