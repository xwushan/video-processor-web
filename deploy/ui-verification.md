# 界面验证

## 1.3.6 批量抽样与临时样片

预估最多随机选取 3 个视频，只上传这些样本；调整参数沿用同一组样本，正式制作时补传其余视频。所有视频仍展示预计大小，抽中行标记实际试编码，其他行标记抽样推算并扩大参考范围。较长结果列表在卡片内滚动并固定表头。

样片与缩略图在制作、参数/视频修改、取消、刷新、关闭或离开处理页面时清理。请求绑定每次预估的标识，旧页面清理不会影响新样片。服务端每 30 秒检查续期，失联超过 10 分钟或服务重启时清理遗留样片，保留上传原文件以支持续传。

- 55 项 Python 回归和 12 项 Node 网络测试通过。新增 100 个视频只上传、试编码 3 个，补传后任务完整包含 100 个；覆盖旧上传会话升级、未知时长推算、取消最后一个编码、清理失败重试、清理权限、旧页面标识、续期保存、失联和重启清理。
- 独立 CPU Docker 容器通过 H.264/H.265/MKV、实际样片/缩略图/Range、断点续传、同名文件、音轨、水印、下载、ZIP 和快速暂停恢复的 HTTP 验证。
- 浏览器导入 6 个自生成视频，只上传 3 个并生成 3 组样片，另外 3 个显示按时长推算；实际样片可播放且保持 320×240 分辨率。修改参数立即删除服务端样片，恢复原参数后仍需重新预估。刷新页面也删除样片，已上传的 3 个原视频仍在。读取视频信息时快速清空列表不会被旧异步结果覆盖，也没有控制台错误。
- 浏览器通过故意延迟分块上传的本机测试代理开始制作：补传前样片已删除，补传其余 3 个视频后，正式任务的 6 个视频均完成。增加独立创建状态，后台状态轮询不会提前解锁补传中的制作按钮；缓存失效或上传错误可继续重试。
- 本地截图 `deploy/ui-batch-estimate.jpg` 为抽样与推算结果，不纳入源码。测试仅使用独立数据卷及自生成视频。

## 1.3.5 上传连接恢复

分块上传及上传会话、预估进度读取遇到断线、超时或临时网关错误时，最多自动重试 4 次，按 1、2、4、8 秒等待。上传成功前不重复计入进度；取消操作会中止当前请求和等待。读取已有会话失败时保留续传标识，仅在会话不存在或损坏时新建。创建预估及正式任务的 POST 请求不自动重试。

- 12 项 Node 网络测试通过，覆盖响应丢失、重试上限、400/401/409/413 不重试、503 恢复、POST 不重试、等待/请求期间取消、超时及响应截断。
- 使用独立 Docker 容器、数据卷和本机故障代理测试真实浏览器。在首个分块写入前断开一次，并在第二个分块成功写入后丢弃响应；浏览器自动重试，完成预估。上传文件 SHA-256 与源文件一致。
- 两视频批次先上传第一个视频，再持续断开第二个视频的连接。4 次重试后显示中文续传提示，制作按钮保持禁用；恢复连接后再次预估，复用同一个会话，只上传第二个视频的分块，两个视频均预估成功。
- 本地截图 `deploy/ui-upload-reconnect.jpg` 和 `deploy/ui-upload-recovered.jpg` 为故障注入测试的错误提示及恢复结果，不纳入源码。测试过程中浏览器出现的连接错误由故障代理主动制造。

## 1.3.4 视频列表空状态

桌面双列布局中，未选择视频时列表填满卡片标题下方的可用空间，拖拽提示居中；选择视频后恢复按内容排列，清空列表后重新填满。平板和手机保留自然高度。

- 在 1728×1080 下验证空列表底边距离卡片底边 21 像素，与卡片内边距一致；空内容区高度为 503 像素。
- 使用自生成视频验证选择与清空，单视频行高仍为 53 像素；1024×768 和 390×844 下空内容区保持 180 像素，页面无横向溢出。
- 浏览器控制台无错误，JavaScript 语法和 Git 空白检查通过。截图保存于本地 `deploy/ui-empty-video-area.jpg`，不纳入源码。

## 1.3.3 模块对齐与编码设备提示

桌面双列布局中，视频文件与水印基础参数、水印预览与处理参数的外框分别保持同高。视频列表按内容排列，行高保持紧凑；处理参数的“预估成品”按钮位于卡片底部。平板和手机采用单列布局，各模块保持自然高度。

编码设备提示去掉显卡型号，使用通用 NVIDIA GPU 编码说明，继续按服务器配置显示自动并发目标。原型号来自运行服务的硬件检测，并非固定值；实际硬件检测和任务资源展示保留。

- 使用用户提供的 5 个视频验证待上传列表及水印预览，未修改源视频。
- 在 1728×1080 和 1440×900 下检查 CPU、GPU 和自动模式：两组卡片上下边缘一致，自动模式的 6 项参数正常排列，列表行高为 53 像素。
- 在 1024×768、390×844、320×740 下验证单列布局，页面无横向溢出；320 像素宽度下设备说明保持在可视区域内，提示不含本机显卡型号。
- 浏览器控制台无错误，JavaScript 语法和 Git 空白检查通过。桌面截图保存于本地 `deploy/ui-aligned-panels.jpg`，不纳入源码。

## 1.3.2 参数说明与处理进度

处理参数的说明移到对应标题旁的问号按钮，鼠标进入显示、移开隐藏；键盘焦点可读取说明，Escape 关闭。手机点击可查看，提示位置限制在可视区域内。CPU 与 GPU 的质量、策略说明分别显示，自动模式中的 CPU 回退参数保留。

制作期间显示独立任务面板：总体进度、视频数量、并发、资源用量和逐视频进度分别展示。单行文件不再被固定最小高度拉伸；文件名、编码器、速度、状态及进度条各有位置。运行时显示暂停，暂停后显示继续制作，并保留键盘操作焦点。处理记录增加状态标签，调整日期筛选、窄屏按钮和文件信息排列。

清空视频或制作完成后会移除上一批预估表格，避免新一批视频误用旧结果；当前参数未预估成功时仍不能开始制作。
