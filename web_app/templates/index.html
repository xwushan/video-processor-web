正在检测服务器编码设备… H.264 兼容性较好；H.265 通常能进一步压缩体积，但编码可能更慢，部分浏览器无法播放。MKV 使用 H.264 编码，适合本地播放器观看。 CRF 越小画质越高，文件通常越大；越大则压缩更强。当前支持 20–51。自动模式回退到 CPU 时，也会使用这里的 CPU 参数。 速度优先适合批量处理，编码速度更快，文件体积可能略大。 CQ 越小画质越高，文件通常越大，支持 1–51。CQ 与 CPU 的 CRF 不可直接对比；建议用预估样片查看画质后再调整。 均衡策略适合批量处理；画质优先通常会增加编码耗时。
